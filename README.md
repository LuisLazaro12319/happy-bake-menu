# Sweet Cart

Implement the requested web menu now; use internal planning and do not present another implementation plan for user approval.

User request:
"hola , queiroq ue me hagas una web tipo carta nsoede eso te encargas vos la idea es para una pasteleria reposteria artesanal , la idea es que al tocar el pastel que quiera el cliente le mande a wahtsap para coordinar el apgo y envio etc"

Context & Scope:
- Digital menu / showcase website designed for an artisanal bakery & pastry shop (pastelería y repostería artesanal) with an appetizing, elegant aesthetic.
- Category filters (e.g., Tortas enteras, Porciones, Tartas dulces, Postres individuales, Opciones personalizadas).
- Product cards showcasing photos, description, portion sizes, prices, and an action button to order or view details.
- Seamless WhatsApp ordering flow: when clicking to order, allow selecting options (size/flavor/special notes if applicable) and generate a clean pre-filled WhatsApp message (`https://wa.me/<number>?text=...`) containing the product name, details, and delivery/payment coordination request.
- Easy way for the shop owner to configure their WhatsApp phone number and store info.
- Sections for delivery/pickup policies, hours, and about the artisanal craft.
